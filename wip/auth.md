# auth.md

DMX Digital is a public website. No authentication is required to access content.

## Agent Registration

This site supports anonymous agent access. No registration or credentials are required.

## Supported Identity Types

- `anonymous` — No identity assertion required. All content is freely accessible.

## Access

All resources at `https://dmxdigital.site` are publicly available without authentication.

## Metadata

- Protected Resource: `/.well-known/oauth-protected-resource`
- Authorization Server: `/.well-known/oauth-authorization-server`
