Featured

Gopher Publishing Tools

A suite of tools for writing and publishing Gopher-formatted content. Write in Emacs, convert Markdown with a keybind, serve as static files. No server, no database, no build step.

embed-gopher

A single HTML file that turns any static site into a Gopher content browser. Drop-in deployment. No dependencies, no build step, no server-side code.

View on GitHub →

markdown-to-gopher

An Emacs Lisp script bound to C-c g. Takes a Hugo Markdown file, strips front matter and syntax, writes a plain text file, and appends to the gophermap automatically.

View on GitHub →

generate‑gophermap.sh

Included with embed-gopher. Converts an existing Hugo site or rendered HTML directory into Gopher content in bulk. Supports Hugo mode and HTML mode.

Part of embed-gopher →
